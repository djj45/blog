这个博客由一个构建脚本和一套模板组成：你在 `posts/` 里写 Markdown，它生成一个纯静态的网站，放到任何地方都能访问。

## 写一篇文章

```bash
npm run new "文章标题"
```

会在 `posts/` 下生成 `文章标题.md`，开头是一段 front matter：

```yaml
---
title: 文章标题
date: 2026-10-15 21:30
tags: [随笔, 工具]
---
```

| 字段 | 说明 |
| --- | --- |
| `title` | 标题。不写时取正文第一行的 `# 一级标题`，再没有就用文件名 |
| `date` | 发布时间，决定排序。不写时取文件名里的日期前缀或修改时间 |
| `tags` | 标签，`[a, b]` 或 `a, b` 都行 |
| `description` | 摘要，用于搜索引擎。不写时自动取第一段 |
| `toc` | 写 `true` 时显示目录：宽屏在正文右侧并高亮当前小节，窄屏在文章开头 |
| `draft` | 写 `true` 时只在本地预览里出现，不会被发布 |
| `slug` | 自定义网址，默认是文件名 |

需要配图时，把文章写成文件夹：`posts/我的文章/index.md`，图片和它放在一起，用 `./图片.png` 引用。

## 预览与发布

```bash
npm run dev     # 本地预览，保存即刷新
npm run build   # 生成 dist/，把这个文件夹上传到任意静态托管即可
```

Markdown 能写成什么样，见 [Markdown 写作速查](./markdown-guide/index.md)。
